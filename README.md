# Reefside AI Labs plugin repository

One Jellyfin plugin catalog for plugins maintained by `jellyfin-ai-labs`.
`manifest.json` currently includes **Animated Album Art** and its published stable versions.
The format follows [Jellyfin's plugin repository documentation](https://jellyfin.org/posts/plugin-updates/).

## Install in Jellyfin

After publishing this repository as `jellyfin-ai-labs/jellyfin-plugin-repo` with a `main` branch,
add this URL under **Dashboard → Plugins → Repositories**:

```text
https://raw.githubusercontent.com/jellyfin-ai-labs/jellyfin-plugin-repo/main/manifest.json
```

Install a compatible plugin from the catalog and restart Jellyfin. Animated Album Art's
initial release targets Jellyfin ABI `12.1.0.0`; older servers will not see a compatible version.
If you use a different repository name or default branch, adjust the URL above.

## Automatic updates

`.github/workflows/update-manifest.yml` checks all repositories in `plugins.json` when
it receives a `repository_dispatch` event with type `plugin-release`. A plugin's publish
workflow should send this notification **after its ZIP and manifest assets finish uploading
successfully**, so the updater can read the completed release. Dispatch payloads do not
change the configured sources or checkout ref; the updater always uses this repository's
default branch and `plugins.json`.

The workflow also runs every week on **Mondays at 06:17 UTC** as a fallback for missed
notifications and commits `manifest.json` only when it changes.
It can also be run manually under **Actions → Update plugin manifest → Run workflow**,
including after adding a plugin or publishing a release. GitHub schedules may be delayed, and scheduled
workflows in public repositories are disabled after 60 days without repository activity.
See [GitHub's schedule documentation](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule).

The workflow uses the built-in `GITHUB_TOKEN`; no extra secrets or changes to plugin
repositories are required for polling public releases. It needs permission to push to
the default branch. Branch protection or organization policies that block the bot's direct
pushes must be configured to permit these manifest updates. The workflow must be on the
default branch for scheduled and repository dispatch runs.

Release notifications use a GitHub App installation token generated by the **sending
plugin repository's** workflow. The App needs **Contents: read and write** permission and
must be installed on this central repository. The sending workflow needs access to the
Actions variable `PLUGIN_REPO_APP_CLIENT_ID` and secret `PLUGIN_REPO_APP_PRIVATE_KEY`;
this central updater does not need either credential. See the
[App token action](https://github.com/actions/create-github-app-token) and
[repository dispatch documentation](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#repository_dispatch).

The updater reads each stable release's `manifest.json` asset, validates the plugin GUID,
version, ABI, and release ZIP URL, and verifies the ZIP's MD5 against the manifest when
importing a new or changed version. Drafts and prereleases are excluded. Releases without
a manifest asset are retried on subsequent runs, allowing time for packaging to finish.
Invalid metadata or download failures fail the run without writing the central manifest.

Versions are sorted numerically, newest first. Existing versions and plugin entries are
retained, including those no longer present upstream. To withdraw a version, remove its
upstream release/manifest first and then remove the central entry; removing only the central
entry will cause it to be imported again. Removing a source from `plugins.json` stops its
updates; remove its entry from `manifest.json` separately to withdraw the plugin.

## Add another plugin

Add the plugin's GitHub repository and stable GUID to `plugins.json`:

```json
{
  "repository": "jellyfin-ai-labs/another-plugin",
  "guid": "THE-GUID-FROM-THE-PLUGIN"
}
```

Each stable release must publish a `manifest.json` containing exactly one Jellyfin plugin
entry with that GUID, plus the ZIP assets referenced by its versions. Animated Album Art's
[publish workflow](https://github.com/jellyfin-ai-labs/animated-album-artwork/blob/master/.github/workflows/publish.yaml)
already produces these assets. Plugin identity and compatibility metadata come from each
release's manifest rather than being duplicated here.

## Run locally

Requires Python 3.12+ and an authenticated [GitHub CLI](https://cli.github.com/).
No Python packages are required.

```sh
python3 -m unittest discover -s tests -v
python3 scripts/update_manifest.py
```

Review the resulting `manifest.json` diff before committing a manual update.
